## Description

This table tests how changes to the Transformer base configuration affect English-to-German translation on the newstest2013 development set. Unlisted cells retain the base model’s values. The configuration columns specify the number of layers $N$, model dimension $d_{model}$, feed-forward dimension $d_{ff}$, number of heads $h$, key and value dimensions $d_k$ and $d_v$, dropout $P_{drop}$, label smoothing $\epsilon_{ls}$, and training steps. Outcomes are development perplexity, development BLEU, and parameter count. The reported perplexities are per wordpiece and are not comparable to per-word perplexities.

Rows (A) vary the number and dimensions of attention heads while holding computation constant. One head gives 24.9 BLEU, 0.9 below the best listed setting, while quality also falls when the number reaches 32. Rows (B) reduce $d_k$ and show lower BLEU, which the authors interpret as evidence that computing compatibility is not easy. Rows (C) vary depth, model width, and feed-forward width; the paper summarizes these results as larger models performing better. Rows (D) vary dropout and label smoothing, with the authors highlighting dropout as important for avoiding overfitting. Row (E) replaces sinusoidal encodings with learned positional embeddings and produces nearly the same result as the base model: 25.7 versus 25.8 BLEU.

The base configuration has 65 million parameters, 4.92 perplexity, and 25.8 BLEU after 100K steps. The final big configuration increases $d_{model}$ to 1024, $d_{ff}$ to 4096, and $h$ to 16; after 300K steps it reports 213 million parameters, 4.33 perplexity, and 26.4 BLEU.
